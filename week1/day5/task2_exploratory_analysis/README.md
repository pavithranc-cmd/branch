# Task 2: Exploratory Data Analysis (Week 1 · Day 5)
Analyses the cleaned data from Task 1: summary statistics, `groupby().agg()`, correlation, the five Day 4
business questions, a `pd.merge` with `data/department_budget.csv` (**ILLUSTRATIVE values**) and a pivot table.

| File | Purpose |
|---|---|
| `src/analysis.py` | Reusable analysis functions. Writes the three report CSVs |
| `notebooks/exploratory_analysis.ipynb` | Each analysis step with outputs and interpretation |
| `data/clean_data.csv` | Snapshot copy of `../task1_data_cleaning/data/clean_data.csv`, written by `analysis.py` |
| `data/department_budget.csv` | Hand-made lookup table. Values are illustrative, not real company data |
| `reports/summary_statistics.csv`, `correlation_matrix.csv`, `pivot_table.csv` | Saved results |

Run Task 1 first, then: `python week1/day5/task2_exploratory_analysis/src/analysis.py`

Findings and limitations are in the [Day 5 README](../README.md#7-summary-statistics-reportssummary_statisticscsv).
